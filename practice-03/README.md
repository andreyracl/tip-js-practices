## Отладка и клавиатура

Точка останова — в handleTaskListClick на строке чтения card.dataset.taskId.
Значения при клике по #task-list > [data-task-id="4"] button[data-action="toggle"] .action-label:

event.target — span.action-label, event.currentTarget — #task-list;

button.dataset.action — "toggle", card.dataset.taskId — "4", после Number — 4;

результат setTaskCompleted(currentTasks, 4, true) — { ok: true, tasks: [...] } (5 полей сводки: 4/3/1/75.0%).

Клавиатура: Tab переводит фокус на кнопки карточек, Enter/Space активируют. После toggle фокус остаётся на кнопке той же задачи; после удаления задача исчезает — фокус возвращается на активный фильтр. Отказ для 777 и 4abc: сообщение об ошибке, сводка не меняется.

## Вывод

Логика ПР2 подключена к DOM без дублирования: task-service.js не знает о document, а main.js только вызывает сервис и обновляет представление. Удаление и переключение статуса меняют сам массив currentTasks, а не только DOM. Ключевые ошибки, которые пришлось устранить: поиск кнопки через closest (иначе клик по вложенному span не срабатывал), проверка Number.isSafeInteger на границе обработчика, разделение currentTasks и видимой выборки (иначе фильтр «Все» терял скрытые записи).
